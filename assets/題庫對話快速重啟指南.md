## 📚 題庫結構（共 4 個題庫）

### 1. 一般業題庫（羅杰晟）
- **題數**：725 題
- **章節**：17 章
- **數據格式**：外部 JSON（兩段式載入）
  - `web/data/raw/chapters.json` - 章節索引（陣列格式）
  - `web/data/raw/chapter1.json` ~ `chapter17.json` - 各章節題目
- **載入方式**：`selectSource('luo')` → `loadChaptersData()` fetch 索引 → 轉為 `{"1": {...}}` 物件存到 `window.LUO_DATA`；進入章節時才逐章 fetch
- **原始檔**（腳本用）：`data/raw/chapters.json` + `data/raw/chapter1.json` ~ `chapter17.json`

### 2. 甲業題庫
- **題數**：1011 題
- **章節**：20 章（A1-A20）
- **數據格式**：單一整包 JSON（已不是內嵌在 HTML）
- **檔案**：`web/data/raw/jia_data.json`（runtime 用）/ `data/raw/jia_data.json`（腳本用）
- **載入方式**：`selectSource('jia')` → `fetch('./data/raw/jia_data.json')` → `normalizeQuestions()` 把 `"1"-"4"` 答案轉 `"A"-"D"` → 存到 `window.JIA_DATA`

### 3. 技術士題庫
- **題數**：100 題
- **章節**：5 章
- **數據格式**：外部 JSON（兩段式載入）
  - `web/data/raw/chapter_zhian_index.json` - 章節索引（陣列格式）
  - `web/data/raw/chapter_zhian_1.json` ~ `chapter_zhian_5.json` - 各章節題目
- **載入方式**：`selectSource('zhian')` → fetch 索引 → 轉為物件存到 `window.ZHIAN_DATA`；進入章節時逐章 fetch

### 4. 有機溶劑題庫
- **題數**：359 題
- **章節**：7 章
- **數據格式**：單一整包 JSON
- **檔案**：`web/data/raw/organic_data.json`（runtime 用）/ `data/raw/organic_data.json`（腳本用）
- **載入方式**：`selectSource('organic')` → `fetch('./data/raw/organic_data.json')` → 存到 `window.ORGANIC_DATA`

## 🎯 網站功能清單

### 核心功能
- ✅ **三種練習模式**
  - 📖 練習模式：選完馬上知道對錯，附詳細解析
  - 📝 小考模式：每頁一題，題目與選項隨機排列
  - 🏆 大考模式：從全部題目隨機抽出 80 題（`APP_CONFIG.EXAM_QUESTION_COUNT`）
- ✅ **鍵盤快捷鍵**
  - `1-4` 或 `A-D`：選擇答案
  - `Enter`：下一題
  - `←→`：切換題目
- ✅ **錯題本**：自動記錄答錯題目（localStorage key `mistakeBook`）
- ✅ **學習進度追蹤**：localStorage key `progress`，可匯出/匯入/分享 JSON
- ✅ **深色模式**：切換深/淺色主題
- ✅ **平靜配色**：低飽和冷色調（`body.calm` class）
- ✅ **專注模式**：答題時隱藏 banner、進度條與提示
- ✅ **自動跳下一題**：練習模式下可啟用（1.5 秒）
- ✅ **題目朗讀**：分段朗讀 + 暫停/繼續 + 速度滑桿（0.5x ~ 2x，存於 `SETTINGS.speakRate`）
- ✅ **連對計數**：練習中顯示 `CURRENT_STREAK` / `MAX_STREAK`
- ✅ **作答計時**：`QUIZ_TIMER` 顯示單次測驗經過時間

### Google Drive 備份
- ✅ **手動備份/還原**：匯出/匯入進度 JSON
- ✅ **自動備份**：可設定間隔（15 分鐘 ~ 6 小時）
- ✅ **OAuth 2.0 PKCE**：純前端實作，token 交換走 Cloudflare Worker 代理
- ✅ **OAuth 代理**：`https://cpc-oauth-proxy.ben900415.workers.dev`（`web/config.js` 內 `OAUTH_PROXY_URL`）

### ⚠️ 重要注意事項

1. **部署根目錄是 `web/` 不是 repo 根** — `wrangler.jsonc` 設 `pages_build_output_dir: "web"`。根目錄的 `index.html` 只做 302 跳轉到 `/web/`。Dashboard 設定要和檔案一致，否則部署失敗（git 歷史顯示此處反覆出問題）。
2. **runtime 用的題庫在 `web/data/raw/`**，**腳本用的題庫在 `data/raw/`** — 兩份要保持同步。`update_embedded_data.py` / `update_embedded_json.py` 負責同步。`scripts/` 下的腳本預設讀寫 `data/raw/`。
3. **Service Worker 快取名稱** — `sw.js` 內 `CACHE_NAME = 'cpc-quiz-v2'`。每次改 JS/CSS 要同步 bump `web/index.html` 內 `<script>` / `<link>` 的 `?v=2` query string，否則使用者會卡在舊版。
4. **CSP** — `web/index.html` 的 `<meta http-equiv="Content-Security-Policy">` 已允許 `https://www.googleapis.com` 與 `https://cpc-oauth-proxy.ben900415.workers.dev`，新增外部資源要記得加進去。
5. **`_headers` 設定 `Service-Worker-Allowed: /`** — 讓 `/sw.js` 的 scope 能擴展到根目錄，**不要拿掉**。
6. **不要把 `package.json` 從 repo 拿掉** — `tests/e2e.test.js` 透過 `npm test` 觸發（Playwright 為 devDependency）。Cloudflare Pages 不會把 Node 構建用在純靜態站上。
7. **本地起服務用 `python3 -m http.server 8080`**（從 `web/` 內），不要直接 `file://` 開 `index.html` — SW 註冊與 `fetch` 都需要 http(s) protocol。

## 🐛 常見問題與解決方案

### 問題 1：章節列表顯示空白
**原因**：題庫數據格式不一致 — 一般業/技術士是「外部 JSON 索引 + 逐章 fetch」；甲業/有機溶劑是「單一整包 JSON」。`selectSource()` 內四個分支各自 fetch 對應檔案。

**解決**：
1. 打開 DevTools Network 看 fetch 是否回 200
2. `console.log(window.LUO_DATA / JIA_DATA / ZHIAN_DATA / ORGANIC_DATA)` 確認資料有沒有進到記憶體
3. 對照 `web/app.js` 的 `selectSource()`（`app.js:97` 附近）確認分支條件

### 問題 2：Service Worker 卡在舊版
**原因**：`CACHE_NAME` 與 `<script src="...?v=N">` 的版本號沒同步更新。

**解決**：
1. 改 `web/sw.js` 的 `CACHE_NAME`（例：`cpc-quiz-v3`）
2. 改 `web/index.html` 內 `config.js` / `app.js` / `style.css` 的 `?v=N` 為同一個新號
3. 推送後等部署完，再請使用者 `Ctrl+Shift+R` 強制刷新一次

### 問題 3：學習進度 / 錯題本在切換題庫時錯亂
**原因**：`CHAPTERS` 是共用變數，切題庫時被覆蓋。

**解決**：用獨立變數保存各題庫數據（這在 `app.js` 內已實作好）：
- `window.LUO_DATA` - 一般業
- `window.JIA_DATA` - 甲業
- `window.ZHIAN_DATA` - 技術士
- `window.ORGANIC_DATA` - 有機溶劑

若某題庫的章節渲染跑掉，檢查對應 `window.XXX_DATA` 是否為非空物件。

### 問題 4：瀏覽器快取問題（CSS/JS 看起來沒生效）
**解決**：
- 強制刷新 `Ctrl+Shift+R`
- 或在 URL 後加 `?v=<timestamp>`
- 確認 `?v=2` query string 與 `sw.js` 的 `CACHE_NAME` 已同步更新

### 問題 5：Cloudflare Pages 部署後內容沒更新
**原因**：`wrangler.jsonc` 與 Dashboard 的 `pages_build_output_dir` 不一致（git log 顯示此問題反覆出現，最近一次修正 commit：`0a8a5ce`）。

**解決**：
1. Dashboard → Pages → 專案 → Settings → Builds → Output directory 應為 `web`
2. `wrangler.jsonc` 內 `pages_build_output_dir` 應為 `"web"`
3. 兩者一致後重新部署

### 問題 6：Google OAuth 失敗 / 無法備份
**檢查**：
- `web/config.js` 的 `OAUTH_PROXY_URL`、`OAUTH_REDIRECT_URI` 是否仍有效
- Google Cloud Console 內該 OAuth Client 的「Authorized redirect URIs」是否包含 `OAUTH_REDIRECT_URI`
- Worker 代理 `cpc-oauth-proxy.ben900415.workers.dev` 是否仍部署中

## 📝 關鍵代碼邏輯

### 題庫載入流程（`web/app.js` 內 `selectSource()`，`app.js:97` 附近）
```javascript
// 入口：首頁點題庫卡片 → 觸發 selectSource(src)
function selectSource(src) {
  CURRENT_SOURCE = src;
  document.querySelector('.banner p').textContent = SOURCE_NAMES[src];

  if (src === 'luo') {
    // 一般業：fetch 章節索引，再進入章節時逐章 fetch
    loadChaptersData().then(function(data) {
      window.LUO_DATA = data;     // 物件格式 {"1":{...}, "2":{...}}
      CHAPTERS = data;
      goScreen('mode-select');
    });
    return;
  } else if (src === 'jia') {
    // 甲業：單一整包 JSON，內含所有章節與題目
    fetch('./data/raw/jia_data.json')
      .then(r => r.json())
      .then(function(data) {
        window.JIA_DATA = data;
        for (var k in data) {
          if (data[k].questions) {
            normalizeQuestions(data[k].questions);   // "1"-"4" 答案轉 "A"-"D"
          }
        }
        CHAPTERS = data;
        goScreen('mode-select');
      })
      .catch(function(err) {
        console.error('載入甲業題庫失敗:', err);
        alert('載入甲業題庫失敗，請檢查網路連線');
      });
    return;
  } else if (src === 'zhian') {
    // 技術士：兩段式，索引 + 逐章
    fetch('./data/raw/chapter_zhian_index.json')
      .then(r => r.json())
      .then(function(data) {
        var obj = {};
        data.forEach(function(ch) { obj[String(ch.id)] = ch; });
        window.ZHIAN_DATA = obj;
        CHAPTERS = obj;
        goScreen('mode-select');
      });
    return;
  } else if (src === 'organic') {
    // 有機溶劑：單一整包 JSON
    fetch('./data/raw/organic_data.json')
      .then(r => r.json())
      .then(function(data) {
        window.ORGANIC_DATA = data;
        for (var k in data) {
          if (data[k].questions) {
            normalizeQuestions(data[k].questions);
          }
        }
        CHAPTERS = data;
        goScreen('mode-select');
      });
    return;
  }
}

### 答案正規化（`web/app.js:251` 附近）
```javascript
function normalizeAnswer(q) {
  var map = {"1":"A","2":"B","3":"C","4":"D"};
  if (q.answer === "1" || q.answer === "2" || q.answer === "3" || q.answer === "4") {
    q.answer = map[q.answer];
  }
  return q;
}

function normalizeQuestions(questions) {
  if (!questions) return [];
  questions.forEach(function(q) { normalizeAnswer(q); });
  return questions;
}
```
答題判斷一律用 `"A"-"D"`，原檔是 `"1"-"4"` 的會在載入階段一次轉完。

### 畫面切換
沒有 router，只有 `goScreen(id)` 切換 `.screen` div 上的 `.active` class。所有畫面都是 `web/index.html` 內 inline 的 div（`#home` / `#mode-select` / `#chapter-select` / `#quiz-screen` / 設定 modal / 進度 modal）。
